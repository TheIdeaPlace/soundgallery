# River Voicing Glass

Each of The Chat Place's events plays its Glass sound, then River says what it was. It's useful for
learning the sounds, or for hearing what happened without having to remember which sound is which.

Made by Kelly Ford with Claude. The tones are The Chat Place's own Glass sounds, generated by
app-kit's `sounds/generate.py`. The voice is Kokoro-82M's `af_river`, an Apache-2.0 speech model, run
locally. No recordings of people were used.

Where River said an event's name wrongly, she says a few different words: "A chat needs you" for
Needs you, "File, changed" for File changed, and "Answer is sent" for Answer sent. Every file was
checked by transcribing it back.
