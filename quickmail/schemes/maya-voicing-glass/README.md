# Maya Voicing Glass

Each of QuickMail's events plays its Glass sound, then Maya says what it was. It's useful for
learning the sounds, or for hearing what happened without having to remember which sound is which.

Made by Kelly Ford with Claude. The tones are QuickMail's own Glass sounds, generated by app-kit's
`sounds/generate.py`. The voice is Kokoro-82M's `af_heart`, an Apache-2.0 speech model, run locally.
No recordings of people were used. Every file was checked by transcribing it back.
